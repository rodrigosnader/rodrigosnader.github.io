Sizes of infinity

2026 · May 12 · 3 min read · Essay

Mathematicians say one infinity can be bigger than another, and that kinda sounds to me as nonsense. If both go on forever, what could bigger even mean?

Counting

When they say a list (or a set) is bigger than another, they seem to mean: count set A, count set B, and compare the two numbers. Five apples is more than three because counting A lands on a bigger number than counting B.

For infinite sets, that doesn't really apply, because we can never end counting A or B. There is no end — that's the definition of infinity. So what do mathematicians mean when they say one infinite is bigger than another?

Pairing

Apparently, there's a way to check if one bag has more marbles than another without counting — by pairing them up. Pull a marble from A, pull a marble from B, set them down together. Repeat. If we run out of B but still have A in hand, A has more.

This is a different operation. We don't need to know the number in either bag. We don't need numbers at all.

For finite sets, the two definitions agree — if A has 5 marbles and B has 3, both methods say A is bigger. For infinite sets, only the pairing one is even well-defined. Counting needs an end; pairing doesn't.

So when mathematicians extended the notion of "size" to infinite sets, pairing seems to have been the only candidate left standing.

Two sets have the same size if we can pair their elements one-to-one with nothing left over on either side.

It seems like bigger for an infinite set isn't really the same concept as bigger for a finite one, and most of my confusion seems to have come from the word itself. We call both of them bigger, but they come from different definitions — even in math, the symbols give them away:

3 < 5   (finite: comparing counts)

|A| < |B|   (infinite: comparing by pairing)

ℕ vs ℝ

So an example is: if you try to pair ℕ (the positive integers) against ℝ (the reals between 0 and 1), apparently no matter how you arrange the pairing, ℝ always has elements left over. This is a famous result (Cantor's theorem) in the 1870s, and it looks like the cleanest case of the pairing definition actually finding a difference between two infinities. ℝ comes out bigger than ℕ — but only in the sense of pairing, not in the everyday counting one.

So the original question — "can one infinity be bigger than another?" — kind of ends up with a not-so-friendly answer:

Well, it depends on your definition of bigger.
