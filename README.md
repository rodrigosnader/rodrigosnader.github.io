# Blog — Rodrigo S. Nader

Blog estático em HTML/CSS/JS puro.

## Rodar local

```bash
python3 serve.py
```

Servido em http://localhost:8765 (no-cache, bom pra dev).

## Estrutura

- `index.html`, `about.html`, `writing.html`, `notes.html`, `links.html` — páginas
- `posts/` — posts publicados (`bayes.html`, `inside-glass.html`, etc.)
- `drafts/` — rascunhos
- `references/` — material de apoio
- `style.css`, `script.js` — estilo e JS globais
- `writing-style.md` — guia de estilo canônico da escrita
